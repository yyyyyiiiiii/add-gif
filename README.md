# pull-gif

Pulling gifs. Now only `gifbox.me` supported

![App screenshot](./screenshots/app.png)

## Project Setup

### Install

```bash
$ npm install
```

### Keys

Before dev / build, export API key for requests making

```bash
export GIFTBOX_API_KEY=`${YOUR_API_KEY}
```

### Development

```bash
npm run dev
```

### Build

```bash
# For windows
npm run build:win
```

```bash
# For macOS
npm run build:mac
```

```bash
# For Linux
npm run build:linux
```
